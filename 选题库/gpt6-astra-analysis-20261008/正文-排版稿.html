实测GPT-6新模型：能力大涨，账单也翻了倍

OpenAI 喊出「欢迎来到 AGI 时代」，但账单上每百万输出 token 50 美元的标价，让「AGI」听起来更像「AM I」。

这是 GPT-6 Astra 发布后最真实的注脚：能力确实跃升了，价格也跟着翻了一倍多。

能力跃升在哪：三个真正突破的场景

相比 GPT-5.6 Sol，Astra 的突破集中在「持续执行完整任务」上。

第一个突破是专业软件操作。Astra 能直接打开 KiCad 做电路板设计、用 FreeCAD 建 3D 模型、在 Blender 里建模再转到 Unreal Engine 5，全程无需人工切换窗口（R-08）。这不是「写段代码」的升级版，是「操控电脑干活」的新物种。

第二个突破是长程编码。Terminal-Bench 4.0 测试中，Astra 得分 57.9%，比 5.6 的 37.3% 高出 20 个百分点（R-05）。更关键的是，它能在长任务中保留关键信息，不再被迫压缩上下文丢细节。

第三个突破是科学研究。Terminal-Bench Science 0.1 测试中，Astra 达到 64.6%，而 5.6 只有 22.4%（R-05）。差距不是 10 个点，是 3 倍。

这三个场景的共同点：任务长、需要持续操作、专业门槛高。 普通写文案、做 PPT 的场景，5.6 就够了，不用为 3 倍价格买单。

定价翻 2.5 倍：OpenAI 在赌什么？

Astra 的标准 API 价格：输入 10 美元/百万 token，输出 50 美元/百万 token（R-02）。而 5.6 是输入 4 美元、输出 20 美元（R-03）。输入涨 150%，输出涨 150%。

OpenAI 的逻辑是：效率提升抵消成本。Terminal-Bench Science 中，Astra 完成同类任务的成本比 5.6 低约 31%（R-06）。翻译成白话：虽然 token 单价贵了，但完成任务需要的 token 少了，总成本反而降。

但这个逻辑有个前提：你的任务确实复杂到需要 Astra 的能力。 写周报、改文案、做简单表格，用 5.6 甚至豆包就够了。为复杂任务付 3 倍单价，合理；为简单任务付 3 倍单价，冤。

第三方机构 Artificial Analysis 的数据也印证了这一点：单任务成本比 5.6 高约 75%（R-06）。OpenAI 说的「成本降低」和第三方说的「成本升高」，不是矛盾，是任务复杂度不同。

踩坑清单：三个不该用 GPT-6 的地方

1简单文案场景

定价 3 倍，能力溢出 3 倍。用 5.6 或国产模型，性价比更高。

2对安全性有要求的任务

Astra 在网络安全基准上表现突出（ExploitBench 100%，R-07），但 OpenAI 也明确限制了它的用途——不会执行高级安全任务（如生成漏洞概念验证）。你的需求如果踩在这个边界上，要么找替代方案，要么接受限制。

3需要监控的场景

Astra 的不当行为率 2.4%，比 5.6 的 22% 低很多（R-07）。这是好事。但 OpenAI 加入了「未对齐监控」，合法任务也可能被系统暂停。如果你的工作流不能容忍中断，5.6 反而更稳。

一句话决策树

用 GPT-6 Astra 的前提，是你先知道什么时候不用它。

  • • 任务专业复杂（3D/代码/科学）→ 用 Astra，贵但有道理
  • • 任务简单日常（文案/表格）→ 用 5.6 或国产平替，省 60% 成本
  • • 任务涉及安全边界 → 先测 5.6 能不能做，不行再升级

能力越强，越要守住「够用就行」的底线。
