```

│  第一层：自动化门禁（gate-check.py）                               │
│  ─────────────────────────────────                               │

│  输出：PASS / WARN / BLOCK                                        │
│  阻断：BLOCK → exit 7，硬拦发布                                   │
│  脚本：gate-check.py（唯一入口，2026-10-13 重构后）                │
├─────────────────────────────────────────────────────────────────┤
│  第二层：人工复核（REVIEW.md）                                     │
│  ─────────────────────────────────                               │
│  职责：主观判断、语境理解、风格把控                                │
│  检查项：R1-R6致命红线 / H1-H14质量规范（语境相关部分）             │

│  输出：审核意见 + 修改建议 + 红线判定                              │
│  阻断：红线项 FAIL → 稿件作废；其他项可协商                        │

├─────────────────────────────────────────────────────────────────┤
│  第三层：发布终检（G7清单）                                         │

│  检查项：12项发布清单（链接/图片/排版/敏感词最终确认）              │

│  文档：gate-G7-check.py + 发布前清单                              │
└─────────────────────────────────────────────────────────────────┘
```

## 二、各层职责边界

### 第一层：自动化门禁（gate-check.py）

**原则**：机器能判的，人不做。

| 维度 | 示例 | 判定方式 |
|------|------|---------|
| **硬性规则** | H8<200字、H-注入残留 | 正则/计数，无歧义 |
| **量化指标** | H9段落>3句、金句密度 | 阈值明确，可标准化 |
| **词表匹配** | 禁用词、元话语、紧迫诱导词 | 固定词表，精确匹配 |
| **结构检测** | G8骨架类型、H10输出结构 | 模式识别，确定性高 |
| **外部脚本** | H14 AI味 | subprocess调用，有fallback |

**不包含**：
- 内容准确性判断（需要领域知识）
- AI味的主观感受（"像不像人写的"）
- 标题创意性评估
- 段落逻辑连贯性
- 数据引用是否可追溯

---

### 第二层：人工复核（REVIEW.md）

**原则**：机器判不了的，人来看。

| 维度 | 示例 | 判定方式 |
|------|------|---------|
| **致命红线** | R1-R6（虚假宣传、涉政等） | 人工通读，一票否决 |
| **语境相关** | H14 AI味（"读起来像不像人写的"） | 人工感受，参考H14分数 |
| **内容质量** | 逻辑连贯性、数据准确性 | 人工审核，逐项确认 |
| **风格把控** | 调性一致性、品牌声音 | 人工判断，主观但重要 |
| **AI参与比例** | 是否如实标注 | 人工核对，防止虚报 |

**不包含**：
- 重复第一层已检查项（除非发现第一层有漏洞）
- 机械计数类检查（交给脚本）

---

### 第三层：发布终检（G7清单）

**原则**：最后一道关，只问"能不能发"。

| 维度 | 示例 | 判定方式 |
|------|------|---------|
| **内容完整** | 标题/正文/结尾/配图齐全 | 清单核对 |
| **链接有效** | 所有URL可访问 | link-check.py 自动验证 |
| **图片合规** | 封面图尺寸、尾图合规 | 人工+脚本混合 |
| **敏感词最终确认** | verify-all.py 结果 | 脚本验证 |
| **发布配置** | 群发/评论开关/排版预览 | 人工确认 |

**不包含**：
- 第一层已检查项（H8/H9/禁用词等）
- 第二层已审核项（红线/内容质量）
- 只做"最终确认"，不做新检查

## 四、工作流程

### 正常流程（目标状态）

```
主笔写作
    ↓
第一层：gate-check.py --verbose
    ↓ BLOCK → 主笔修改 → 重跑
    ↓ WARN → 记录，可继续
    ↓ PASS
    ↓
第二层：审核岗人工复核（REVIEW.md）
    ↓ 红线FAIL → 稿件作废
    ↓ 其他FAIL → 协商修改
    ↓ PASS
    ↓
第三层：发布终检（G7清单）
    ↓ 任何FAIL → 延迟发布
    ↓ 全部PASS
    ↓
发布
```

### 快速通道（短稿/速评）

```
主笔写作
    ↓
第一层：gate-check.py --no-humanizer --verbose
    ↓ BLOCK → 主笔修改 → 重跑
    ↓ PASS（H14跳过，人工后续补审）
    ↓
第二层：简化人工复核（只查红线R1-R6）
    ↓
第三层：发布终检（简化清单）
    ↓
发布
```
