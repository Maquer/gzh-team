# 分级放行机制 v1.0

> 用途：根据稿件类型决定检查严格度，避免一刀切
> 基准：5篇稿件实操数据 + 四模型评审共识
> 更新日期：2026-10-13

---

## 一、分级标准

| 级别 | 适用场景 | 检查范围 | 阻断规则 |
|------|---------|---------|---------|
| **L1 重点稿件** | 头条/爆款目标/系列首发 | 全量检查（14项） | BLOCK=硬拦，WARN=必须处理 |
| **L2 常规稿件** | 日常更新/内容填充 | 核心检查（8项） | BLOCK=硬拦，WARN=记录但不阻断 |
| **L3 实验性稿件** | 新题材试水/风格探索 | 基础检查（4项） | BLOCK=硬拦，WARN=忽略 |

---

## 二、各级别检查项

### L1 重点稿件（全量检查）

**必须通过**：
- H8 字数 ≥200（BLOCK）
- H-注入残留 = 0（BLOCK）
- H-占位符 = 0（BLOCK）
- H-元数据 = 0（BLOCK）
- H11 敏感词 = 0（BLOCK）
- H12 绝对化用语 = 0（BLOCK）
- H13 广告法违规 = 0（BLOCK）
- H15 AI标识合规（BLOCK）

**建议通过**：
- H9 段落≤3句（WARN）
- H-禁用词 = 0（WARN）
- H-元话语 = 0（WARN）
- 标题策略 ≥5（WARN）
- 金句密度 ≥1处/千字（WARN）
- 紧迫诱导词 = 0（WARN）
- H14 AI味 ≤5分（WARN）
- G8 结构多样性（WARN）

**命令**：
```bash
python3 gate-check.py <稿件> --verbose
python3 verify-all.py <稿件>
```

---

### L2 常规稿件（核心检查）

**必须通过**：
- H8 字数 ≥200（BLOCK）
- H-注入残留 = 0（BLOCK）
- H-占位符 = 0（BLOCK）
- H11 敏感词 = 0（BLOCK）
- H12 绝对化用语 = 0（BLOCK）

**建议通过**：
- H9 段落≤3句（WARN）
- H-禁用词 = 0（WARN）
- H14 AI味 ≤5分（WARN，可用--policy-mode）

**命令**：
```bash
python3 gate-check.py <稿件> --no-humanizer --verbose
# 或
python3 gate-check.py <稿件> --policy-mode --verbose
```

---

### L3 实验性稿件（基础检查）

**必须通过**：
- H8 字数 ≥200（BLOCK）
- H-注入残留 = 0（BLOCK）

**建议通过**：
- H-禁用词 = 0（WARN）

**命令**：
```bash
python3 gzh-precheck.py <稿件>
```

## 三、使用流程

```
1. 确定稿件级别
   ↓
   ├── 头条/爆款目标 → L1
   ├── 日常更新 → L2
   └── 试水/探索 → L3
   ↓
2. 选择对应检查命令
   ↓
3. 运行检查
   ↓
4. 处理结果
   ├── BLOCK → 必须修改
   ├── WARN（L1）→ 必须处理
   ├── WARN（L2）→ 记录但不阻断
   └── WARN（L3）→ 忽略
   ↓
5. 记录级别到选题卡
```

---

## 四、选题卡标注

在选题卡中添加「稿件级别」字段：

```markdown
## 元信息
- 选题ID：xxx
- 稿件级别：L1/L2/L3
- 理由：头条目标/日常更新/试水
```

## 五、级别判定指南

| 场景 | 建议级别 | 理由 |
|------|---------|------|
| 政策类稿件 | L2 | 官方内容，AI味可用--policy-mode豁免 |
| 行业分析 | L1 | 信息密度高，需要全量检查 |
| 教程/干货 | L1 | 步骤必须准确，需要全量检查 |
| 新闻速报 | L2 | 时效性优先，核心检查即可 |
| 个人感悟 | L3 | 风格探索，基础检查即可 |
| 系列稿件 | L1（首发）/ L2（后续） | 首发需要全量，后续可简化 |
| 短稿/速评 | L2/L3 | <500字，可简化检查 |

---

## 六、与三层架构的关系

| 架构层级 | 检查类型 | L1 | L2 | L3 |
|---------|---------|:--:|:--:|:--:|
| 第一层（自动化） | gate-check.py | 全量 | 核心+policy | precheck |
| 第二层（人工） | REVIEW.md | 全量 | 简化（红线） | 跳过 |
| 第三层（终检） | G7清单 | 全量 | 简化 | 跳过 |
