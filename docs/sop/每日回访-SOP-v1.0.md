> 触发：每日 22:00 Apple Reminders 提醒
> 责任人：08回访岗（或主理人代执行）

---

## 回访流程

### Step 1：打开后台
```
微信 → 我 → 设置 → 通用 → 关于我们 → 订阅号助手
或：微信 → 发现 → 小程序 → 搜索"订阅号助手"
```

### Step 2：检查数据
打开「数据统计」→「全部发表」，查看：
- 今日阅读数
- 新增关注
- 留言/点赞/分享

### Step 3：回复互动
- 回复所有评论（哪怕只是一个表情）
- 置顶优质评论
- 引导讨论（用互动钩子库里的模板）

### Step 4：记录台账
打开 `docs/发布台账.md` →「数据回收表」
填入当日数据（阅读/分享/在看/留言/来源分布/完读率/新增关注）

### Step 5：思考优化
问自己：
- 哪篇文章表现好？为什么？
- 哪篇文章表现差？为什么？
- 明天写什么？用什么标题公式？

## 互动钩子速查

**投票选择**：
```
你遇到过这种情况吗？
A. 遇到过，很头疼
B. 没遇到过，但想了解
C. 完全没概念
评论区告诉我你的选择～
```

**经历分享**：
```
你在【场景】遇到过类似问题吗？
欢迎在评论区分享你的故事
我会整理优质评论到下期文章
```

**观点碰撞**：
```
你怎么看【争议点】？
A. 支持 B. 反对 C. 其他
评论区见！
```

---

## 注意事项

1. **必须每日执行**：即使数据为零也要记录
2. **回复要真诚**：不要复制粘贴，根据评论内容个性化回复
3. **台账及时更新**：当天数据当天记，不要堆积
4. **发现异常立即上报**：如阅读量突然暴跌、负面评论等
