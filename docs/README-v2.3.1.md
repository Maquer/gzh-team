# 公众号写作团队 v2.3.1 — 说明文档

> 本文档说明本仓库的定位、脱敏处理范围、保留内容及其用途，以及使用方式。

---

## 一、仓库定位

本仓库是 **公众号写作团队职责手册** 的开源版本，包含：

- 团队架构设计（10 个岗位的职责、边界、交接契约）
- 生产流程规范（选题→素材→结构→撰写→审核→排版→发布→回访）
- 门禁检查脚本（自动验证稿件质量）
- 品牌资产与排版模板

**核心目标**：让任一角色可被替换成别人或工具，交接不丢信息、责任不糊。

---

## 二、脱敏处理

### 已删除内容

| 类别 | 说明 | 示例 |
|------|------|------|
| **选题库** | 实际选题内容、素材包、正文草稿 | `选题库/*.md` |
| **复盘档案** | 发布数据回收、阅读量、完读率等运营数据 | `复盘档案/*.md` |
| **跨团队交流** | 团队会议记录、评审报告、讨论纪要 | `跨团队交流/*.md` |
| **团队评审** | 专项审计、红蓝军对抗记录 | `_team-review-20260921/` |
| **述职/踩坑** | 团队内部述职报告、经验教训 | `述职报告*.md` |
| **已发布文章** | 排版稿 HTML、正文草稿 | `*.html` |
| **编译缓存** | Python 字节码缓存 | `__pycache__/` |
| **红蓝对抗记录** | 测试用例数据 | `red-blue/` |

**删除原因**：
- 真实账号数据、阅读数、评论等属于个人隐私
- 选题内容涉及未发布商业内容
- 会议记录包含团队内部讨论，不适合公开

## 五、使用方法

### 5.1 查阅职责

```bash
# 查看完整团队手册
cat TEAM.md

# 查看特定岗位
cat docs/roles/04-writer.md  # 主笔职责
cat docs/roles/05-review.md  # 审核职责
```

### 5.2 运行门禁检查

```bash
# 基础门禁
python3 gate-check.py 稿件.md

# G7 发布前检查
python3 gate-G7-check.py 稿件.md --cover 封面.jpg --html 排版稿.html

# AI 味检测
python3 gate-H14-check.py 稿件.md
```

### 5.3 参与开发

```bash
# 克隆仓库
git clone https://github.com/Maquer/gzh-team.git

# 提交修改
git add .
git commit -m "修复某问题"
git push
```

## 六、注意事项

1. **本文档不含**：实际文章内容、发布数据、团队内部讨论
2. **门禁脚本仅验证格式**：不含敏感词库，需配合 `yuwen-publish-precheck` 使用
3. **数据标准来自历史**：各阈值基于实际发布数据，建议自建基线后调整
4. **本仓库为模板**：可根据自身需求修改岗位职责和门禁规则
