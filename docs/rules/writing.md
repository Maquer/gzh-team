# 写作纪律

> 位置：gzh-team 外部规则层 | 维护人：主笔 + 审核 | 更新频率：每次事故后
> 建库时间：2026-09-20 | 依据：v1.6 架构调整"职责与规则分离"

## 适用范围

所有主笔产出的正文内容（Markdown 成稿）。

## 纪律清单（4 条）

### 1. 数字必须带来源

正文出现数据 → 括号标 `R-xx` 或来源名。写不出来源的数字，删掉或改成模糊表述。

- ✅ "月活 1200 万（来源：XX 财报 Q2）"
- ❌ "月活 1200 万"
- ❌ "月活约一千万"（无来源，改回具体数字或删除）

### 2. 一处只讲一件事

一段内出现两个论点 → 拆两段。手机屏上一个论点读不完。

- ✅ 段 1：AI 写作工具的痛点 → 段 2：AI 写作工具的解决方案
- ❌ 段 1：AI 写作工具的痛点 + 解决方案混在一起

### 3. 删掉所有过渡废话

禁用词库（脚本口径：train-check.py BANNED 常量）：
- 首先 / 其次 / 此外 / 总而言之 / 不可否认
- 需要关注的是 / 接下来 / 需要注意的是 / 换句话说
- **禁用"是"字头**：「AI 是…」「内容是…」「品牌是…」

**去味口诀**：开头说人话，每段配例子，少用"是"字头，多跟读者"你"说话。

### 4. 不用紧迫感诱导词

禁用词库（脚本口径：train-check.py URGENCY 常量）：
- 强档（命中即违规）：速看 / 马上删 / 惊呆了 / 震惊 / 必看 / 全网首个 / 全网第一
- 弱档（参考用，正当语境可用）：立即 / 紧急 / 限时

**要制造紧迫感用具体数字**（"24 小时内"、"最后一周"）代替抽象紧迫词。

**对齐微信审核红线**（转载会限流），不是审美问题。

## 脚本判定

- 禁用词检查：`gate-check.py`（BANNED + URGENCY）
- AI 味检查：`humanizer-check` 共享工具（11 条规则，阈值 ≤5 放行 / 6-15 重写≥50% / >25 推倒重写）⚠️ 非本团队自有 skill，为 shared 目录共享工具
- 详细阈值：`docs/rules/standards.md`
