> 来源：`docs/audit/HANDOFF-CONTRACTS-20260926.md` + 各岗位角色卡

## 使用说明

- 每条契约定义：字段名 + 类型 + 是否必填 + 示例 + 来源（角色卡文件及行号）
- 接收方按此格式验收，缺必填字段即退回
- 格式变化需同步更新此文件

## HC-01：04 主笔 → 05 审核（修改记录）

**交接**：04 主笔 → 05 审核
**时机**：04 交稿时附在稿件末尾
**格式**：`YYYYMMDD_选题_修改记录.md`

### 字段定义

| # | 字段名 | 类型 | 必填 | 示例 | 来源 |
|---|--------|------|:----:|------|------|
| 1 | 改动位置 | string | ✅ | `节2 L45` | HANDOFF HC-01 |
| 2 | 原文引用 | string | ✅ | `"这个功能很好用"`（≤10字） | HANDOFF HC-01 |
| 3 | 改前内容 | string | ✅ | `"这个功能很好用"` | HANDOFF HC-01 |
| 4 | 改后内容 | string | ✅ | `"小白也能 3 分钟上手"` | HANDOFF HC-01 |
| 5 | 改动理由 | string | ✅ | `AI味/事实核查/逻辑跳跃/合规` | HANDOFF HC-01 |
| 6 | AI味改前评分 | number | ✅ | `13` | roles/04-writer.md L42 |
| 7 | AI味改后评分 | number | ✅ | `6` | roles/04-writer.md L42 |

### 验收规则
- 缺任意字段 → 退回
- 改前/改后内容相同时 → 退回（无实际改动）
- AI味评分超出范围（>100）→ 退回
