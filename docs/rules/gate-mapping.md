## 使用规则

1. **角色卡是权威来源**：每个岗位角色卡的"工具链"段必须列出该岗位负责的门禁脚本
2. **新增门禁脚本时**：必须同步更新本表 + 对应岗位角色卡
3. **修改门禁脚本时**：必须同步更新对应岗位角色卡的培训段（如有）
4. **审核时**：05 审核岗对照本表确认所有"✅ 必须"门禁已跑
