## 1. 品牌色（从实际资产提取）

| 角色 | 色值 | 用途 | 来源 |
|------|------|------|------|
| **主色（品牌红）** | `#C2453C` | 头像背景、Logo 强调、装饰点缀 | avatar.png / logo |
| **辅助色（纯黑）** | `#000000` | 文字、Logo 主体 | logo-wide |
| **辅助色（纯白）** | `#FFFFFF` | 红底上的文字 | avatar |
| **辅助色（浅灰）** | `#F5F5F5` | 背景、分割线 | 通用 |
| **文字色** | `#333333` | 正文 | 通用 |

---

## 2. 应用规则

| 场景 | 主色用法 | 辅助色用法 |
|------|---------|-----------|
| **首图（封面）** | 装饰元素/色块（面积 ≤20%） | 背景 + 标题文字 |
| **尾图** | 背景色（满铺） | 白色文字 |
| **正文配图** | 点缀色（图标/标签） | 背景 + 主体 |
| **头像** | 满铺背景 | 白色文字 + 红色 Logo |

---

## 3. 字体

- **中文**：思源宋体 / 书法体（与 Logo 字体风格一致）
- **英文**：无衬线体（如 Helvetica / Arial）
- **PIL 可用**：Noto Sans CJK SC（备选）
