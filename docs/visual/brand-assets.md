# 品牌素材（封面 Logo / 印章）

封面脚本 `cover-dynamic.py` 的左上品牌标识和右上印章**优先使用预制图片**，
图片缺失时自动回退字体渲染。本目录说明需要准备什么。

## 需要放置的文件

| 文件 | 尺寸 | 位置 | 用途 |
|------|------|------|------|
| `assets/brand/logo-mixed-transparent.png` | 宽 455（高按等比） | 封面左上 x=58, y=32 | 品牌标识 |
| `assets/brand/seal-uploaded-84.png` | 84×84 | 封面右上 x=760, y=28 | 印章 |

两者均含 alpha 通道（透明底）。未提供时脚本不报错，走字体渲染回退。

## 为什么品牌标识必须用图片

品牌标识是**混排设计**——前两个字用文楷（LXGW WenKai），后两个字用毛笔
（MaShanZheng）。这种设计无法用单一字体逐字渲染复现：字间距、笔画粗细、
基线对齐都是设计的一部分。

所以脚本里有一组硬编码锚点。它们来自母图（宽 455）的实测字间隙：

```
弎 0–105 / 水 113–226 / 野 234–342 / 记 350–455
```

缩放到封面 130px 宽后用于定位两个元素：

- **红色横线**：从「弎」左边缘到「水」右边缘
- **英文副标**：从「野」左边缘开始

换自己的品牌名时，这三个数（0 / 226 / 234）必须按你的字间隙重新量取，
否则红线和英文会错位。量取方法见下。

## 字体缺字坑（重要）

`MaShanZheng-Regular.ttf` **不含「弎」(U+5F4E)**，渲染出来是空心方框 □。

- 品牌标识：用图片规避
- 印章动态回退：必须用 `NotoSerifCJK-Bold.ttc`（含该字），脚本已固定
- 仓库里旧的 `seal-circle-84.png` 就是栽在这个坑上——里面的「弎」是方框，**已废弃勿用**

任何含生僻字的标识，先验证字体再决定渲染方式：

```python
ImageFont.truetype(path, 24).getbbox('你的字')   # 返回全 0 或异常 = 缺字
```

## 从白底设计稿抠图（可复用方法）

拿到的是白底 JPEG 设计稿时：

1. **裁掉标注行**：按行统计非白像素数，找到主体与说明文字的分界
2. **白底转透明**：`alpha = clip((245 - 亮度) × 255 / (245 - 90), 0, 255)`
3. **量字间隙**：统计 alpha>60 的列分布，连续空列（>3px）即为字间

第 2 步的 245/90 是白点上界与红点下界，按实际图调整；抗锯齿边缘靠这个
线性区间自然过渡，不需要额外羽化。

## 字体分工（当前定稿）

| 区域 | 字体 | 理由 |
|------|------|------|
| 品牌标识 | 预制图片 | 混排设计，字体不可复现 |
| 内容摘要区 | 文楷 LXGW WenKai | 信息承载层，可读性优先 |
| 右侧热点大字 | 毛笔 MaShanZheng | 视觉锚点，气势优先 |
| 印章回退 | Noto Serif CJK Bold | 覆盖生僻字 |

## 版式坐标（900×383）

右侧热点区 `ax=580`，让装饰组（圆环 + 24 点点阵，外半径 85）居中于右侧
可用区。左侧摘要行受 `MAX_SUM_W=400` 约束，最远到 x≈466，留约 100px 间距。
`ax` 若回退到 500 一档，装饰组会压在画面中间，左侧空、右侧挤。
