---

## 1. 定义

**首图** = 公众号文章封面图，即头条/次条在列表页展示的缩略图。

---

## 2. 尺寸规范

| 位置 | 比例 | 像素 | 备注 |
|------|------|------|------|
| 头条封面 | 2.35:1 | 900×383 | 部分场景被裁成 1:1 |
| 次条封面 | 1:1 | 200×200 或 300×300 | 推荐正方形 |
| 正文配图 | 16:9 或 1:1 | 宽 1080/900px | 高不限，避免过长 |

**安全区**：核心内容居中 ±15%（应对 1:1 裁切场景）。

---

## 3. 设计风格

### 3.1 配色
- **主色**：品牌红 `#C2453C`
- **强调色**：品牌红（同主色）
- **辅助色**：浅灰 `#F5F5F5`

### 3.2 字体
- **字体族**：Noto Sans CJK SC
- **字重**：标题 Bold / 正文 Regular
- **字号**：标题 ≥48px / 正文 ≥24px（900px 宽下）

### 3.3 布局
```
┌─────────────────────────────────────┐
│  [品牌标识区]                        │  ← 账号名称/Logo（左上或居中）
│                                     │
│  [主标题区]                          │  ← 标题文字（居中，≤20字）
│                                     │
│  [副标题/标签区]                     │  ← 可选，补充说明
│                                     │
│  [装饰元素]                          │  ← 几何图形/色块（不抢主体）
└─────────────────────────────────────┘
```

**品牌标识区**：必须出现，位置固定在左上角或居中顶部，字号 ≥24px。

---

## 4. 生产流程

1. **主笔**出配图指导（含 prompt，见 §5）
2. **排版岗**审 prompt → 执行生图（即梦/sensenova）
3. **排版岗**跑 H11/H12 门禁（OCR 抽检）
4. **排版岗**PIL 后处理（去水印 + 加品牌标识）
5. **发布岗**上传确认

---

## 5. 配图指导模板（主笔填写）

```markdown
### 配图指导

| 字段 | 值 |
|------|-----|
| 类型 | 首图（封面） |
| 比例 | 2.35:1（900×383） |
| 主体描述 | （英文，≤30词） |
| 风格关键词 | （Mondo/极简/科技等） |
| 必须包含 | 账号名称、标题文字 |
| 禁止出现 | 中文文字（OCR 会出错） |
| prompt 末尾 | no text, no watermark, no lettering |
```

---

## 6. 门禁规则

| # | 规则 | 检查方式 | 通过标准 |
|---|------|---------|---------|
| H11 | 无中文错字 | `apple-vision ocr --level fast` | 无命中 |
| H12 | 无 prompt 元数据 | `apple-vision ocr --level fast` | 无 `ultrawide`/比例参数 |
| H13 | AI 标识合规 | 肉眼 + OCR | 去水印则后台开声明 |
| H-品牌 | 品牌标识出现 | 肉眼 | 账号名称可见 |
| H-安全区 | 核心内容居中 | 肉眼 | 不贴边 |

## 9. 生产工具（v1.1）

```bash
cd /var/minis/shared/gzh-team
python3 head-tail-card.py --title "标题" --sub "副标题" --date 2026.09
# 输出 assets/out/首图-<标题前12字>.png + 尾图-关注型.png
# --only head|tail 单独出图；--next "下篇标题" 加预告行；--no-seal 去印章
```

零 AI 依赖：全部文字 PIL 绘制，字体 Noto Sans/Serif CJK（index=2 = SC 字面），
