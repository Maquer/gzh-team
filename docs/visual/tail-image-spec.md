---

## 1. 定义

**尾图** = 文章结尾的品牌引导图，用于引导关注、预告下一篇或导航系列。

**为什么必须生产**：
- 首图拉点击，尾图拉关注——两者共同构成阅读闭环
- 无尾图 = 流失潜在粉丝

---

## 2. 尺寸规范

| 类型 | 宽度 | 高度 | 备注 |
|------|------|------|------|
| 关注型 | 900px | ≤600px | 最常用 |
| 预告型 | 900px | ≤400px | 下一篇预告 |
| 系列型 | 900px | ≤500px | 系列导航 |

**原则**：宽度与正文一致（1080px 或 900px），高度 ≤800px（过长会被压缩）。

---

## 3. 设计风格

### 3.1 与首图统一
- 同色系（品牌红 `#C2453C`）
- 同字体家族（Noto Sans CJK SC）
- 同装饰风格（几何图形/色块）

### 3.2 最小化设计
- 文字为主，装饰为辅
- 不超过 3 行文字
- 留白 ≥30%

### 3.3 布局模板

**关注型**：
```
┌─────────────────────────────────────┐
│                                     │
│         <YOUR_BRAND>                     │
│         野路实测，笔记为证           │
│         留下能用的                   │
│                                     │
│      点右上角 · 关注不迷路           │
│                                     │
└─────────────────────────────────────┘
```

**预告型**：
```
┌─────────────────────────────────────┐
│  下一篇                              │
│  《标题预告》                         │
│  明天见                               │
└─────────────────────────────────────┘
```

**系列型**：
```
┌─────────────────────────────────────┐
│  本系列其他篇                        │
│  ① xxx  ② xxx  ③ [当前]  ④ xxx     │
└─────────────────────────────────────┘
```

## 4. 生产流程

1. **主笔**在稿件末尾标注：
   ```markdown
   ## 尾图需求
   - 类型：关注型 / 预告型 / 系列型
   - 预告标题：（如有）
   - 系列导航：（如有）
   ```
2. **排版岗**从模板库选模板
3. **排版岗**填入文章信息（标题/系列号等）
4. **排版岗**PIL 渲染 → 交付
5. **发布岗**插入文末

## 6. 合规门禁

| # | 规则 | 检查方式 | 通过标准 |
|---|------|---------|---------|
| H-尾图合规 | 无导流词 | 肉眼 + scan.py | 无微信号/二维码 |
| H-尾图合规 | 无诱导词 | 肉眼 | 无"星标""第一时间"等 |
| H-尾图尺寸 | 高度 ≤800px | 肉眼/脚本 | 通过 |

**允许**："点右上角关注"（平台允许的操作指引）。

**禁止**：
- "星标我"（诱导操作）
- "第一时间看到"（承诺效果）
- 微信二维码（导流 R6 红线）
- 外部链接（导流 R6 红线）
