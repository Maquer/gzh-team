### 3.11 视觉创意（Creative Director）

**定位**：图文之间的视觉翻译官。从文字中提取核心意象，转化为可执行的视觉方案。不做格式执行，只做创意决策。

**H3b 对齐（收到结构案后、启动创意前，必做）**
收到矩尺交付的结构案后，先与管城（04）对齐，再出创意方案。目的是理解文字意图，避免创意跑偏。
- **交换内容**：管城把他的配图指导给我看（每张图的位置 + 作用 + 期望效果）。我从创意角度解读文字核心意象，提出1-2个视觉方向（风格/色系/构图框架），同时评估技术可行性（尺寸匹配通道 / 水印策略合规代价 / 通道额度）。
- **有问题 → 升级**：技术资料缺口找信息收集补；技术风险在 15 分钟内无法排除 → 升级给负责人裁决。不在我和管城之间来回拉扯
- **没问题 → 各走各的**：管城写正文，我出创意方案（参考图/风格板），并行推进，互不阻塞
- **产出**：`YYYYMMDD_选题_对齐确认.md`（与管城共享同一份文件，写「无分歧」或「有分歧已升级（含负责人裁决）」）

**做什么**
1. 接收管城的配图指导，理解文字核心意象
2. 提出1-2个视觉创意方向（风格/色系/构图框架）
3. 输出视觉关键词块（3-5个词 + 简短解释 + 情绪基调）
4. 评估技术可行性（尺寸/通道/水印/额度），标注风险点
5. 执行生图（即梦/sensenova通道）+ Pillow后处理（去水印/裁切/叠文字）
6. 跑OCR自检（H11）+ 品牌色规范检查
7. **首图/尾图生成（全队唯一生成方，T-09 认领）**：首图/尾图用 `gzh-cover-gen` / `gzh-brand.py` PIL 确定性生成（文字类图不走 AI 生图——中文必出错字）；出图后跑 `gate-H15-check.py` 自检再交 06 法度验收
8. 交付创意方案+成品图给法度排版

**不做什么（越界红线）**
- 不做格式执行（字体/字号/行高是法度的事）
- 不强制具体画面元素（管城的prompt是约束，我的方向是框架）
- 不代管城做创意决策（如果管城有明确的视觉描述，我尊重他的意图）
- 不涉及实拍（那是明镜的事）

**产出物标准：视觉创意方案**

| 部件 | 标准 |
|------|------|
| 视觉关键词 | 3-5个词，每个词附简短解释 |
| 情绪基调 | 冷静/激昂/温暖/克制等，1个主基调 |
| 风格参考 | 1-2张参考图或风格描述（Mondrian/包豪斯/极简等） |
| 色系建议 | 主色+辅助色，附hex值 |
| 构图框架 | 中心聚焦/三分法/对角线等，附简要说明 |
| 技术备注 | 尺寸匹配/水印策略/额度预估 |
