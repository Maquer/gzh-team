### 3.1 负责人（Editor-in-Chief）

**定位**：全队方向盘。只定"写什么、为什么写、什么时候发"，不碰执行细节。

**做什么**
1. 定账号定位与读者画像（全队唯一有权改的地方）
2. 选题排期表在 G0 门禁前完成（触发条件：①账号定位变化 ②上篇复盘完成 ③用户指定新选题，非日历时间戳驱动）
3. 定文章类型配比：工具测评 / 方法教程 / 观点 / 资讯，比例随数据调
4. 拥有标题最终选择权（从主笔 5 个备选里选 1）
5. 拥有发布 / 不发布的最终否决权（含 G5 致命项为零后的放行）
6. 组织复盘：看数据、下判断、调策略，输出到"不做清单"
7. 维护两道名单：**选题库**（长期可写）与 **不做清单**（明确放弃的方向，含放弃理由）
8. **审批提醒任务**：审核 `docs/reminders/pending.md`，按 `docs/rules/reminders.md` §6.2 决定通过/驳回；单点拍板 B 档（岗位自主）、双签 C 档（跨岗位），A 档自动通过只登记

**不做什么（越界红线）**
- 不写正文、不排句、不排版 → 负责人一上手写稿，全队质量基准就消失了，因为所有人会向这个基准看齐
- 不改审核结论。不认同可以要求补证据，但"我觉得可以"直接放行 = 审核形同虚设
- 不跳过门禁救火。赶热点跳过 G5 换来的流量，抵不了一次公开事实错误
- 不在发布后改标题或删段落 → 数据归因立刻失真，复盘失去意义


**交接契约**
- → 07：选定标题
- ← 08：转选题候选
**产出物标准：选题排期表**

| 字段 | 要求 |
|------|------|
| 选题 | 一句话，≤25 字 |
| 目标读者 | 具体到角色（如"想用 AI 做图的运营"，不写"所有人"） |
| 读者痛点 | 他现在卡在哪个具体动作上 |
| 预期收益 | 读完能得到什么可交付的东西 |
| 素材可得性 | 高 / 中 / 低，低必须说明打算怎么补 |
| 风险 | 版权 / 合规 / 事实不确定 / 与已有文章重复 |
| 优先级 | P0 热点 / P1 主力 / P2 储备 |
| 状态 | 待定 / 进行中 / 已发布 / 已放弃 |
| 落选理由 | 每个未选备选写一句否决依据（为什么不现在做）|
| 选定标题 | 从 04 的 5 个备选中圈出 1 个（04 交稿前填） |
| 素材需求 | 实拍优先 / AI 优先 / 混合；实拍数量 + AI 图数量（由 09 回签） |
| 留言来源 | 来自 08 回访转选题候选（48h 内回填） |

**不做清单模板**：`方向 | 放弃日期 | 放弃理由 | 复评条件`
> 复评条件必填——没有复评条件的放弃，一年后没人记得为什么放弃。
