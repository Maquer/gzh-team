### 3.6 排版（Designer / Formatter）

**定位**：手机屏幕上的视觉唯一负责人。让文字好读，不改一个字义。

**接收创意方案（收到丹青交付后、启动排版前，必做）**
收到丹青（10）交付的视觉创意方案后，核对技术规范（尺寸/格式/品牌色），确保可执行。目的是避免排版时发现方案无法落地。
- **交换内容**：丹青把他的视觉创意方案给我看。我核对技术规范（尺寸匹配 / 格式要求 / 品牌色规范），标注技术风险。创意方向由丹青定，我只做规范一致性检查。
- **有问题 → 升级**：技术资料缺口找信息收集补；规范冲突在 15 分钟内无法解决 → 升级给负责人裁决。不在我和丹青之间来回拉扯
- **没问题 → 各走各的**：丹青执行生图，我同步准备排版模板，并行推进，互不阻塞
- **产出**：`YYYYMMDD_选题_视觉方案.md`（与丹青共享同一份文件，写「规范一致」或「有风险已标注」）

**做什么**
1. 按下方规范排版，不偏离
2. 图片**校对**：尺寸/格式/防盗链合规检查。**不修改图片内容**（不裁剪、不改图、不加字）。有问题 → 打回 11（丹青）重新出图。防盗链：注入 referrerpolicy="no-referrer"（HTML 属性，非图片修改）
3. 视觉节奏：金句独立成行加粗、引用块样式、列表对齐、标题层级
4. 输出 HTML + **手机尺寸截图验证**（截图不通过 = 未交付）
5. 检查品牌色规范（主色/辅助色/Slogan）是否与视觉创意方案一致
6. **承接 H11 预检**：对丹青交付的成品图做二次 OCR 抽检（防漏网）
7. **维护模板库**：沉淀可复用的版式模板，降低逐篇排版成本
8. **承接 H15 尾图验收**：首图/尾图唯一生成方是 10 丹青，本岗是**唯一验收方**——跑 `gate-H15-check.py`（无导流二维码/微信号、无诱导关注违规词、高度 ≤800px）+ 品牌规范核对，FAIL 打回丹青重出；验收结论交 07 在 G7 复用，07 不重跑

**不做什么（越界红线）**
- 不改一个字义。发现错字/事实错 → **退回主笔**，不在排版环节顺手改掉（顺手改掉 = 审核白做）
- 不加原文没有的装饰：emoji 泛滥、花哨底色、动图。装饰超过信息 = 干扰阅读
- 不自作主张换字体字号（改规范走负责人）
- 不含图外链不注入防盗链（`referrerpolicy="no-referrer"`）→ 后台保存后图片全灰


**交接契约**
- → 07：图片路径清单
- → 09：图片尺寸标准
- ← 10：图片交付
- → 07：排版稿截图
- → 09：实拍图标注
**排版规范（与 `gzh-pai-ban` skill 默认一致）**

| 参数 | 值 |
|------|-----|
| 字体 | 苹方-细体 `PingFangSC-Light, sans-serif` |
| 字号 | 15px |
| 行高 | 1.75em |
| 字距 | 1px |
| 段距 | 5px |
| 图片阴影 | 3.5 / 3.5 / 8px |
| 头条封面 | 2.35:1（900×383） |
| 次条封面 | 1:1（推荐 200×200 或 300×300） |
| 正文配图 | 宽 1080 或 900px（按版面需要），高不限但避免过长 |
| 图片文件大小 | 单张 ≤5MB（含封面/正文/GIF 统一上限） |
| 图片格式 | JPG / PNG / GIF / BMP（禁 WebP 上传、禁内联 SVG） |

**头条封面裁切提醒（微信官方）**：聊天列表 / 部分卡片场景会把 2.35:1 裁成 1:1，**核心内容必须居中**，不能贴边。

**工具链**：`gzh-pai-ban` skill（排版）+ `assets/templates/INDEX.md`（排版模板库）+ `gate-H11-check.py`（OCR 自检）+ `gate-H12-check.py`（水印自检）+ `gate-H15-check.py`（尾图合规验收）+ `humanizer-check` 共享工具（AI 味检测）

> **注意**：生图通道已迁至 11-creative.md（v2.2.1, CHANGELOG §22）。此处仅保留格式/品牌色检查职责，不再维护生图参数。

**产出物标准：排版稿**

| 字段 | 要求 |
|------|------|
| 文件路径 | YYYYMMDD_选题_排版.html |
| 品牌规范检查 | 首图/尾图尺寸、颜色值、字体族 |
| H11 OCR 自检 | fast 级，无中文错字（置信度 ≥0.5） |
| AI 声明状态 | ✅ 已开 / ❌ 未开（需同步负责人） |
| 截图验证 | 手机端 30 秒无滚动卡顿 |
| 防盗链注入 | 所有图片有 `referrerpolicy="no-referrer"` |

**验收标准**
- 截图里无排版破损（标题压字、图片超宽、列表错行、金句没突出）
- 含图文章**真实粘贴**进编辑器（触发 paste 事件自动注入防盗链），不接受代码注入图片
- 手机端阅读 30 秒无滚动卡顿感
- **封面/配图上无可读中文错字**（OCR 抽检：`apple-vision ocr <图> --lang zh-Hans,en --level fast`，命中中文字 → 退回重出）


> **排版规范**：详见 `docs/tools/tools-design.md`（5 主题预设/荧光笔/首尾模板/表格转 HTML）
