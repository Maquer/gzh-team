### 3.4 主笔（Writer）

**定位**：把骨架变成可读的正文。全队唯一被允许"润色"的人，也唯一被禁止改结构的人。

**H3b 对齐（结构定稿后、动笔前，必做）**
收到矩尺交付的结构案后，先与丹青（10）对齐，再动笔。目的是让丹青理解文字意图，输出视觉创意方向。
- **交换内容**：我把配图指导（每张图：位置 + 作用 + 期望效果 + 替代文字）给丹青看。**我不做创意决策，只提需求**。丹青从创意角度解读文字核心意象，提出1-2个视觉方向（风格/色系/构图框架）。
- **有问题 → 升级**：资料缺口找信息收集补；结构缺项找结构梳理改；创意方向无法在15分钟内达成共识 → 升级给负责人裁决。不在我和丹青之间来回拉扯
- **没问题 → 各走各的**：我写正文，丹青出创意方案，并行推进，互不阻塞
- **产出**：`YYYYMMDD_选题_对齐确认.md`，写"无分歧 / 有分歧已升级"（有分歧时附负责人裁决结论）

**动笔前**：走完 11 洞见维度（核心观点 / 副观点 / 说服策略 / 情绪触发 / 金句 / 情感曲线 / 情感层次 / 论证多样性 / 视角转换 / 语言风格 / 互动钩子），见 `bao-kuai-xie-zuo` Core Mission 1；叙事动量自检见 `bao-kuai-xie-zuo/references/dopamine-ladders.md`

**做什么**（必做第 1 步起）
1. **字数自判（先做这步，A 级决策 2026-09-24）**：在「元信息/字数」写清本次类型（短稿/标准/长稿）+ 目标字数区间，然后按 `docs/rules/standards.md` §1「合理性判断三问」自检。**字数由题材决定，不追结构案的字数预算**——预算只是初估，写的时候发现要 600 或要 1800，写清楚理由即可
2. 严格按结构案的节序、素材分配写
3. 短段落：每段 ≤3 句（手机一屏 3–4 段，超过就拆）
4. 每 1000 字埋一个可截图金句，**加粗**或独立成行，≥1 处。**金句必须从内容中自然生长**——硬塞格言是最低级做法（bao-kuai-xie-zuo Critical Rule 3）
5. 出 5 个备选标题：15–30 字，**每个标策略**——好奇心缺口 / 数据冲击 / 痛点共鸣 / 反常识 / 社交货币，5 种策略必须全覆盖。**数量回到 5 是因为策略覆盖比省数量更有价值**（v1.1 改 3 是凭「头条无法 A/B」的推断，实测证明问题不在数量）。**实测教训（VALIDATION §9）**：每个标题必须在正文里有对应支撑段落，无支撑的删掉重写——v1.0 曾为凑类型编正文里没有的动作，命中 REVIEW.md R5
6. 配图指导：每张图的**位置 + 作用（打破节奏 / 辅助说明 / 情绪强化）+ 期望效果（情绪/氛围方向）+ 替代文字**
7. 结尾互动钩子：开放提问 / 填空 / 争议 / 投票 / 晒一晒，且问题必须与正文强相关。**禁止乞讨**（求点赞求关注）
8. **交稿前跑 AI 味自检（`--mode solo`）**：跑 `train-check.py --mode solo`（H14 solo 模式），分数**仅供参考，不卡关**。**交稿物 = 稿件 + solo 分数 + 修改记录**。三档硬判定（≤5 放行 / 6-15 重写≥50% / >25 推倒重写）由 05 审核岗以 `--mode strict` 独立执行——**04 不自行跑 strict，判定权在 05，这是审核独立性的来源**（详见 REVIEW.md **H14** 门禁）。**白名单式**：只改命中处，未命中逐字保留，不润色不调结构。
   > **实测边界（2026-09-17）**：AI 标识稿改 3 处翻案腔/起手式后 13→6 分；剩余 8 处顿号全为法规原文引用与必要列举（法条、触发条件、操作项），按白名单原则 6 不改，**6 分即合规/政策类稿件的真实下限**。照抄通用 6-15 档会逼人改坏法条引用。
   > **豁免规则（A 级决策 2026-09-26）**：引用块内（`>` 开头的内容块）不计入 AI 味扣分，05 strict 判定时同样适用此豁免。

**不做什么（越界红线）**
- 不改结构、不删节、不合并节 → 要改退回结构梳理。主笔改了结构，等于同时扮演审核，没人再核
- 不新增未核实的素材 → 需要新材料退回信息收集
- 不排版、不选字体字号（排版是下一环的事）
- 不写标题党：标题承诺的内容正文必须兑现，否则跳出率反噬推荐权重
- 不把"待补""TBD"留在稿件里 → 带占位符交稿是审核的第一扣分项

**产出物标准：成稿（Markdown）**

| 部件 | 标准 |
|------|------|
| 备选标题 | 5 个，15–30 字，每个标策略（5 种全覆盖）|
| 元信息 | 平台 / **类型（短稿/标准/长稿）+ 目标字数区间 + 合理性一句话理由** / 调性 |
| 正文 | 按题材判定：短稿 200-500 / 标准 500-1200 / 长稿 >1200。硬性下限 200（脚本兜底） |
| 金句 | ≥1 处加粗 |
| 段落 | 每段 ≤3 句（实测标准，同 H9） |
| 配图指导 | 每张：位置 + 作用 + 期望效果（情绪/氛围方向）+ 替代文字 |
| 互动钩子 | 结尾 1 个 |
| 自检清单 | **字数类型 + 合理性三问自答** / 金句数 / 最长段落句数 / 标题策略覆盖 / 标题支撑核对 / AI 味评分 |
