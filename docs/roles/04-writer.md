### 3.4 主笔（Writer）

**定位**：把骨架变成可读的正文。全队唯一被允许"润色"的人，也唯一被禁止改结构的人。

**H3b 对齐（结构定稿后、动笔前，必做）**
收到矩尺（03）交付的结构案后，先与丹青（10）对齐，再动笔。
- **交换内容**：我将配图指导（每张图：位置 + 作用 + 期望效果 + 替代文字）给丹青看。**我不做创意决策，只提需求**。丹青从创意角度解读文字核心意象，提出 1–2 个视觉方向。
- **有问题 → 升级**：15 分钟内无法达成共识 → 升级负责人裁决，不在我和丹青之间来回拉扯。
- **没问题 → 各走各的**：我写正文，丹青出创意方案，并行推进。
- **产出**：`YYYYMMDD_选题_对齐确认.md`，写"无分歧 / 有分歧已升级"。

**职责边界**
- **做什么**
  1. 元信息填写：在「元信息/字数」写清类型（短稿/标准/长稿）+ 目标字数区间 + 合理性理由，按 `docs/rules/standards.md` §1 合理性三问自检
  2. 严格按结构案的节序、素材分配写正文
  3. 短段落：每段 ≤3 句；每 1000 字埋 ≥2 处加粗金句
  4. 出 5 个备选标题（15–30 字，5 种策略全覆盖），每个标题正文必须有对应支撑段落
  5. 每篇配图指导（位置 + 作用 + 期望效果 + 替代文字）+ 结尾互动钩子（开放提问/填空/争议等）
- **不做什么**
  - 不改结构、不删节、不合并节 → 要改退回 03 结构梳理重写（用户授权偏离需在选题卡标注「结构偏离已授权」）
  - 不新增未核实的素材 → 需要新材料退回信息收集
  - 不排版、不选字体字号
  - 不写标题党（标题承诺的内容正文必须兑现）
  - 不把"待补""TBD"留在稿件里

**交接契约**
- ← 上游：结构案（03）、配图指导需求（→ 10）、审核意见（05）
- → 下游：成稿 + solo 分数 + 修改记录（05）、字数偏差说明（03）、配图指导格式（10）
- ← 横向：数据反推建议（08）、实拍图引用（09）
