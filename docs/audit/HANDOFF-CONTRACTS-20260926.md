## 契约 1：04 主笔 → 05 审核（修改记录）

**触发**：04 交稿时

**格式**：`YYYYMMDD_选题_修改记录.md`

**字段**：

| 字段 | 说明 |
|------|------|
| 改动位置 | 节号 + 原文引用 10 字内 |
| 改动内容 | 改了什么（原文 → 新文） |
| 改动理由 | 为什么改（AI 味 / 事实核查 / 逻辑跳跃 / 合规） |
| AI 味评分 | 改前分 / 改后分 |

**交付时机**：交稿时附在稿件末尾

**交付时机**：审核报告完成后

## 契约 23：03 矩尺 → 04 管城（结构案交付）

**触发**：03 完成结构案后、04 动笔前

**格式**：`YYYYMMDD_选题_结构案.md`

**字段**：

| 字段 | 说明 |
|------|------|
| 节 | 钩子 / 主体 N / … / 结尾 |
| 节标题 | ≤25 字，一句话概括本节核心 |
| 本节要回答的问题 | 读者读完这一节能干什么 |
| 用哪些素材 | R-xx / R-xx 格式，标注已分配素材 ID |
| 字数预算 | 每节初估（N×M，总预算参考：短稿 200-500 / 标准 500-1200 / 长稿 >1200） |
| 金句位 | ✅/—（标在哪里适合放金句） |

**交付时机**：04 动笔前（结构案是成稿的骨架输入）

## 契约 24：04 管城 → 06 法度（成稿交付）

**触发**：04 写完正文后、06 开始排版前

**格式**：`YYYYMMDD_选题_正文.md`（Markdown 源文件）

**字段（成稿 Markdown 必须含）**：

| 部件 | 标准 |
|------|------|
| 备选标题 | 5 个，15-30 字，每个标策略（5 种全覆盖） |
| 元信息 | 平台 / 类型（短稿/标准/长稿）+ 目标字数区间 + 合理性一句话理由 / 调性 |
| 正文 | 按结构案节序写，短段落（每段 ≤3 句） |
| 金句 | ≥2 处加粗 |
| 配图指导 | 每张：位置 + 作用 + 期望效果（情绪/氛围方向）+ 替代文字 |
| 互动钩子 | 结尾 1 个 |
| 自检清单 | 字数类型 + 合理性三问自答 / 金句数 / 最长段落句数 / 标题策略覆盖 / AI 味评分 |

**交付时机**：06 排版前（成稿是排版的唯一输入）
