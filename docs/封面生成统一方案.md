# 封面生成统一方案

**状态**：已完成（2026-10-14）

## 背景

此前封面生成有两套方案并存：

| 工具 | 特点 | 用途 |
|------|------|------|
| `cover-dynamic.py` | 品牌感强，左文右图 6:4，圆形装饰+锚点大字 | 文章首图 |
| `cover-pipeline.py` | 功能全面，有 OCR 门禁+去水印+多种布局 | 发布前校验 |

两套方案各有所长，但维护成本高，且功能有重叠。

## 统一方案

**决策**：以 `cover-pipeline.py` 为统一入口，增加 `brand` 布局模式。

### 三种布局模式

```bash
# 1. simple - 右对齐标题（适合短标题）
python3 cover-pipeline.py --base pil --layout simple --title "标题"

# 2. structured - 左侧标题栈+清单+日期徽章（适合分析类）
python3 cover-pipeline.py --base pil --layout structured --title "标题" --points "1,2,3" --date "2026.10"

# 3. brand - 左文右图 6:4 品牌版（适合深度文章）
python3 cover-pipeline.py --base pil --layout brand --title "标题" --keyword "锚点" --summaries "行1;行2;行3;行4"
```

### 公共参数

| 参数 | 说明 |
|------|------|
| `--base pil` | 纯 PIL 渐变底图（确定性渲染） |
| `--base jimeng` | AI 生图底图（需配合 `--src`） |
| `--src <路径>` | AI 底图路径 |
| `--style <名>` | 设计师风格（10 种） |
| `--color <名>` | 渐变配色预设 |
| `--out <路径>` | 输出路径 |

### 门禁检测

- **H11 OCR**：fast + accurate 双通道，标题区自动豁免
- **H13 AI 标识**：PIL 模式无需声明，AI 底图需开后台开关

## 已废弃

- `cover-dynamic.py` — 功能已合并到 `cover-pipeline.py --layout brand`
- `cover-card.py` — 旧版固定模板
- `cover-summary.py` — 独立脚本，已废弃

## 迁移指南

### 旧用法 → 新用法

```bash
# 旧：cover-dynamic.py
python3 cover-dynamic.py article.md

# 新：cover-pipeline.py brand
python3 cover-pipeline.py --base pil --layout brand \
  --title "文章标题" \
  --keyword "锚点词" \
  --summaries "行1;行2;行3;行4" \
  --date "2026.10"
```
