# 封面设计新基准（2026-10-06）

## 参考图
- 文件：`photo_96E8A11E.jpeg`（AI面试恐怖谷冲上热搜）
- 来源：用户提供的样板图

## 设计要素拆解

### 1. 品牌标识区（左上）
- **主标**：<YOUR_BRAND>（红色，书法体）
- **副标**：<YOUR_BRAND_EN>（灰色小字）
- **装饰线**：红色横线连接主副标
- **字体风格**：传统书法感 + 现代排版

### 2. 主题区（左下）
- **热搜标题**：AI面试恐怖谷冲上热搜（红色，带下划线）
- **核心观点**：对着假笑脸答题被当成人 / 算法替代不了人的渴望（黑色，大号字体）
- **时间标签**：10月3日 · 秋招季观察（灰色小字）

### 3. 视觉中心（右侧）
- **关键词放大**：恐怖谷（红色，超大号，艺术化处理）
- **副标题**：当算法开始「面试」你（灰色小字）
- **英文**：THE UNCANNY VALLEY（灰色极小）
- **装饰元素**：圆形轮廓 + 点阵环绕

### 4. 底部信息区
- **Slogan**：野路实测，笔记为证：留下能用的（灰色小字）
- **日期标签**：2026.10（红色边框，白底，右下角）

### 5. 印章（右上）
- **样式**：红色圆形印章
- **内容**：垂直排列「<YOUR_BRAND>」
- **英文环绕**：SANS HUI YE JI

## 配色方案
| 元素 | 颜色 |
|------|------|
| 品牌主色 | #C2453C（红色） |
| 品牌辅助 | #787878（灰色） |
| 正文色 | #333333（深黑） |
| 背景 | #FAF8F5（米白） |
| 装饰圆 | #F0D4D0（浅红） |

## 布局结构
- **左60% - 右40%** 分割
- 左侧：文字信息为主
- 右侧：视觉图形为主
- 底部通栏：Slogan + 日期标签

## 字体依赖
- NotoSansCJK-Bold.ttc（正文字体）
- NotoSansCJK-Regular.ttc（辅助字体）
- MaShanZheng-Regular.ttf（毛笔字）
- LXGWWenKai-Regular.ttf（楷体）

## 生成脚本
- **脚本路径**：`/var/minis/shared/gzh-team/cover-new-style.py`
- **使用方法**：`python3 cover-new-style.py`
- **输出**：`选题库/<选题ID>/封面图.png`
