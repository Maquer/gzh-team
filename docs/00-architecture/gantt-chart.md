## 关键阻塞依赖（⚠️ = 高优先级）

| 依赖 | 说明 | 违反后果 |
|------|------|---------|
| **③b → ③c** | ③c 必须在 ③b 完成后启动 | 丹青不知道配图需求，无法出方案 |
| **③b → ④** | ④ 必须在 ③b 完成后启动 | 管城不知道图片方向，无法写配图指导 |
| **③c → ④b** | ④b 必须在 ③c 完成后启动 | 法度没有创意方案，无法执行生图 |
| **④ → ⑤** | ⑤ 必须在 ④ 完成后启动 | 审核没有成稿，无法做审核 |
| **④b → ⑤** | ⑤ 必须在 ④b 完成后启动 | 审核没有成品图，无法检查 H11/H12 |
| **⑤ → ⑥** | ⑥ 必须在 ⑤ 完成后启动 | 排版没有审核通过的稿件 |
| **⑥ → ⑦** | ⑦ 必须在 ⑥ 完成后启动 | 发布没有排版稿 |

## 热点稿压缩模式（T-1 紧急发布）

```
T-1 上午：①②③ 合并（负责人+信息收集+结构梳理，4h内完成）
T-1 中午：③b 快速对齐（15min，只看技术风险）
T-1 下午：③c 创意 + ④ 撰写 + ④b 出图（三岗并行，4h内完成）
T+0 晚上：⑤ 审核 + ⑥ 排版 + ⑦ 发布（3岗串行，2h内完成）
```

> ⚠️ 热点稿压缩时，⑤ 审核和 ⑥ 排版可部分并行（审核通过后立即开始排版），但 G5/G7 永远不可跳。

## 纯文字稿模式（无配图）

```
① 选题 → ② 素材 → ③ 结构 → ③b 跳过（丹青不激活）→ ④ 撰写 → ⑤ 审核 → ⑥ 排版 → ⑦ 发布
```

> 丹青触发条件：配图≥1张时激活。纯文字稿（配图指导为空或全部标注"无图"）跳过 ③b/③c/④b。
