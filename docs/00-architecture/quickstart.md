## 8. 最小可行配置

不是所有人都能凑齐 11 人。合并要保住**独立性**——审核独立性是这套机制里唯一不能妥协的东西。

**1 人版（一个人 + AI）**
- 11 个角色全部自己干，但**必须保留 3 个门禁**：G3 结构案、G5 审核、G7 发布清单
- 关键技巧：**G5 必须换时间窗口**。写完立刻审自己的稿 = 没审。至少隔 4 小时，隔天更好
- G5 用清单勾选，不用脑子想——清单是唯一能在疲惫状态下还能拦住错误的手段
- 可省的门禁：G2 / G4 / G6（用自检清单替代，不阻塞）；**G0 与 G1 永不可省**
- 10/11 岗降级：1 人版不实拍（跳过 H11），不出图（跳过 H3b/H3c/④b），纯文字稿模式

**3 人版**
| 人 | 角色 | 为什么这样合并 |
|----|------|--------------|
| P1 | 负责人 + 审核 | 不写稿，审核独立性天然成立 |
| P2 | 信息收集 + 结构梳理 + 发布 | 都是"想清楚 + 对外"，都不碰正文句子 |
| P3 | 主笔 + 排版 | 都是"呈现"；错字由 P1 审核先拦住，排版只看视觉 |

**5 人版**：1 人版基础上把"信息收集"和"结构梳理"拆开，"审核"和"排版"拆开（审核独立性由专职保证）。

**不可合并的三条**
1. **审核** 不得与撰写、排版、发布中任何一项合并（自己审自己 = 门禁作废）
2. **发布** 不得与主笔合并（发布人改内容 → G7 形同虚设）
3. **负责人** 永远单人，不做轮值（方向会漂移）

## 9. 本周就能用的三件事

1. 建目录 `选题库/`，把 3 个想写的选题按 H1 字段填一遍 → 立刻发现哪个选题素材不够
2. 用 3.3 的结构模板库，为下一个选题选一个模板并填骨架 → 比直接开写快 3 倍
3. 把 3.7 的 G7 十项清单存成备忘录，下次发布逐项勾 → 这一条今天就能拦住 80% 的发布事故

## 附：本手册的假设

| 假设 | 依据 | 若不符，改哪里 |
|------|------|--------------|
| 账号为 AI 自媒体（AI 工具 / AI 效率赛道） | 现有画像与流水线 skill 的默认设定 | 改 3.3 结构模板库（换成你的文章类型） |
| 单账号、图文为主 | gongzhonghao-publish 的定位 | 多账号需在第 7 章资产表加"账号"维度 |
| 与现有工具链打通（gzh-typeset.py / gzh-api-push / 爆款写作） | 已装 skill | 换工具只改各角色"工具"行，职责不变 |

> 本手册是 v1.0，设计基准是"接缝有标准、责任不糊"。用两周后，优先修改**被绕过最多的门禁**和**被投诉最多的交接点**——那是真正需要改的地方。
