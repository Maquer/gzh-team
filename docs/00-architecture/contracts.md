## 4. 交接物契约（Handoff Contracts）

团队不扯皮的真正来源不是分工表，是**接缝处的标准**。10 岗结 9 个单向交接点 + 1 个双向协作点（H3b）（回访岗 §3.8 为手动录入，不进流水线）：

| # | 交接点 | 交接物 | 命名 | 必填字段 | 打回条件 |
|---|--------|--------|------|---------|---------|
| H1 | 负责人 → 信息收集 | 选题排期表 | `YYYYMMDD_选题_选题表.md` | 痛点 / 收益 / 素材可得性 / 风险 | 痛点写不出具体动作，或素材可得性=低且无补救方案 |
| H2 | 信息收集 → 结构梳理 | 素材包 | `YYYYMMDD_选题_素材包.md` | 素材ID / 类型 / 来源 / 置信度 / 抓取日期 | <8 条；A/B 级 <3；无反例；关键数字无链接 |
| H3 | 结构梳理 → 主笔 | 结构案 | `YYYYMMDD_选题_结构案.md` | 节标题 / 本节问题 / 素材ID / 字数预算 / 金句位 | 节无法回答"读完能干什么"；核心论点 >25 字；收益 >1 个 |
| **H3b** | **主笔 + 视觉创意（协作对齐，非单向交接）** | **对齐确认单** | `YYYYMMDD_选题_对齐确认.md` | 配图指导已读（管城提供）/ 视觉方向已确认（丹青提供）/ 分歧点（无则写"无"）/ 升级项（无则写"无"） | 配图指导缺位置或作用；视觉创意未给出方向判断（只做技术讨论不算通过） |
| **H3c** | **视觉创意 → 法度（成品交付）** | **成品图 + 创意方案** | `YYYYMMDD_选题_视觉方案.md` + 图片文件 | 视觉关键词块 / 成品图路径 / H11/H12自检结果 / 品牌色核对 / **图文一致性校验** | **缺成品图；H11/H12未通过；品牌色冲突；成品图与描述不一致** |
| H4 | 主笔 → 审核 | 成稿 | `YYYYMMDD_选题_稿件.md` | 5 备选标题（覆盖 5 策略）/ 正文 / 金句 / 配图指导 / 自检清单 | **元信息未写字数类型+理由**；字数 <200；金句 <1；有占位符；数字无来源 |
| H5 | 审核 → 排版 | 通过稿 | `YYYYMMDD_选题_通过稿.md` + 审核报告 | 报告含三级标注 | 🔴 致命项 >0；报告无行号/原文引用 |
| H6 | 排版 → 发布 | 排版稿 | `YYYYMMDD_选题_排版.html` + 截图 + 封面 | HTML / 手机截图 / 900×383 封面 | 截图未验证；图片无防盗链 |
| H7 | 发布 → 负责人 | 数据回收表 | `YYYYMMDD_选题_数据.md` | 见 3.7 表 + 本次唯一变量 | 无"唯一变量"字段（没填这列，复盘必然跑偏） |

**契约硬规则**
- 每个交接物是**一份文件**，不是一串聊天记录
- 交接物一旦流转，上游不得私自修改 → 需修改必须走打回
- 打回必须写明"哪一条字段不达标"，不接受"再看看"
- 一份选题 = 一个目录：`选题目录/` 下放 H1–H7 + H3b + H3c 全部文件，任何人凭目录即可复原全过程
- **占位符统一 `[待填写]`**（H4–H7 契约硬规则）：H4 主笔成稿出现"资料不足"时统一用 `[待填写]`（预期行为，不扣分）。非标占位符（XX / ___ / xxx / 待补 / TBD）= 内容缺陷 = FAIL。出现 `[待填写]` 时必须在文末追加 `## 信息缺口声明` 小节，逐条列出每个占位符的位置/当前状态/补资料计划。脚本口径：gate-check.py 占位符检查已落地。

## 6. 打回与升级机制

**打回三级**
1. 🟢 **打回本环节**：问题在自己环节能修（主笔字数越界 → 主笔改）
2. 🟡 **打回上游**：问题在上游（发现缺素材 → 退回信息收集；发现结构错 → 退回结构梳理）
3. 🔴 **升级负责人**：满足任一条件 → 开 15 分钟止损会

**升级触发条件**
- 同一交接点打回 ≥3 次
- 上下游对"什么算达标"有分歧且无法在 30 分钟内达成一致
- 审核判定 🔴 致命项且主笔认为不应改
- 发布时间冲突（热点窗口 vs 质量未达标）

**争议裁决顺序**（明确，不用吵架）
1. 有量化标准的 → 按标准（字数下限 200、金句数、置信度）
2. 无标准的 → 看数据（历史同类文章表现）
3. 数据也没有 → 负责人拍板，**但必须把裁决理由写进交接物**（否则下次同样的争议会重演）

**止损规则**：止损会上只有三个合法结论——继续（改什么、谁改、何时）/ 降配（砍到能发的最小版本）/ 砍掉（选题进不做清单，附理由）。不允许"再想想"。
