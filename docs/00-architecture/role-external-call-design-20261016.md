# 岗位外部调用架构设计（2026-10-16）

## 核心原则

**所有岗位技能只能通过外部调用** —— 岗位本身不包含执行逻辑，只负责调度、交接、决策。

## 架构转变

| 维度 | 旧架构 | 新架构 |
|------|--------|--------|
| 岗位定义 | 内嵌执行逻辑 | 调度器 + 交接者 |
| 技能位置 | 角色卡内 | 外部 skill / 工具 |
| 培训重点 | 教执行方法 | 教调用协议 |
| 变更成本 | 改角色卡 | 改 skill（不影响角色） |
| 复用性 | 岗位专用 | skill 跨岗位复用 |

## 岗位卡新结构

```markdown
# 岗位名称（花名）

## 定位
一句话说明这个岗位在流水线中的位置和价值。

## 职责边界
- **做什么**：3-5 条核心职责
- **不做什么**：3-5 条明确红线

## 外部调用
| 调用目标 | 触发条件 | 调用方式 |
|---------|---------|---------|
| skill-name | 何时调用 | `命令或描述` |

## 交接契约
- ← 上游：接收什么
- → 下游：交付什么

## 产出物
- 文件名规范
- 必填字段

## 培训要求
- 理解岗位定位
- 掌握调用协议
- 熟悉交接流程
```

## 培训卡新结构

```markdown
# 岗位培训卡（花名）

## 学习目标
1. 理解岗位在流水线中的位置
2. 掌握外部调用协议
3. 熟悉交接契约

## 调用协议训练
- 何时调用什么 skill
- 如何传递参数
- 如何处理调用失败

## 交接演练
- 模拟上游输入
- 模拟下游交接
- 异常处理

## 考核标准
- 岗位理解：能否准确描述职责边界
- 调用能力：能否正确调用外部 skill
- 交接能力：能否完成交接契约
```

## 本地工具外部化

| 本地工具 | 外部化方式 | 说明 |
|---------|-----------|------|
| `gate-*.py` | 保留本地 + 通过 skill 调用 | 门禁工具，调用简单 |
| `cover-*.py` | 通过 `gzh-cover-gen` skill | 封面生成已 skill 化 |
| `training/train-check.py` | 保留本地 | 培训考核工具 |
