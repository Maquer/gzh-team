# 岗位培训卡（维缆）

## 学习目标
1. 理解岗位在流水线中的位置：全队的对窗口，只做发布动作 + 收数据，不碰内容
2. 掌握外部调用协议：gzh-api-tui-song 推送流程
3. 熟悉交接契约：H6 排版稿 → H7 数据回收表

## 调用协议训练

| 场景 | 调用目标 | 调用方式 | 预期结果 |
|------|---------|---------|---------|
| 获取 API token | `gzh-api-tui-song` token | `gzh-api-tui-song token` | access_token 返回 |
| 上传封面图 | `gzh-api-tui-song` upload | `upload --file cover.jpg` | media_id 返回 |
| 推送到草稿箱 | `gzh-api-tui-song` push | `push --file content.html --title "标题" --thumb media_id` | 草稿 ID 返回 |
| 读取/更新草稿 | `gzh-api-tui-song` get/update | `get-draft --id <ID>` 后 `update --id <ID>` 整篇写回 | 草稿修改生效 |
| G7 发布前 12 项检查 | `yuwen-publish-precheck` | skill 触发"发布前检查" | 12 项清单逐项判定 |
| 事故应急（撤回/改标题） | `gzh-api-tui-song` | 对应 sub-command | 紧急修正发布内容 |

**6 个卡点速记**：AppSecret 只显示一次（存环境变量）/ 40164=IP 白名单 / 48001=公众号未认证 / CRLF 换行报错 / 读草稿必须 POST / 改草稿整篇覆盖。

## 交接演练

### 上游输入
- 模拟输入：排版稿 HTML + 截图（来自 06）、选定标题（来自 01）
- 必填字段检查：G7 12 项是否全绿、封面尺寸是否 2.35:1（900×383）

### 下游交接
- 交付物：发布记录 `YYYYMMDD_选题_发布记录.md` → 08 回访
- 字段要求：发布时间（精确到分钟）/ 发布渠道 / 草稿ID / 时间戳 / 发布截图路径 / 摘要≤120字 / 封面路径 / 失败记录
- 同步交付：数据回收表 → 08（T+1 填，T+7 补）
- 交接确认：下游回复"已收台账/打回+原因"

### 异常处理
- **401 IP 不在白名单**：立即去「基本配置→IP 白名单」添加，不重试 API
- **群发开关未开**：实测 09-25 三篇群发未开→阅读 0，G7 必查此项
- **推送到草稿箱≠发布**：推完必须在公众号后台预览确认后再点发布
- **API 直推备份**：07 不可用时，04 按 `gzh-api-tui-song` skill 接管，并通知 01

## 考核标准

- **岗位理解**：能否说明"发布动作+收数据，不改内容"的边界（0-10 分）
- **调用能力**：能否正确完成 token→upload→push→verify 四步流程（0-10 分）
- **交接能力**：发布记录字段是否完整、G7 12 项是否全绿才发（0-10 分）
