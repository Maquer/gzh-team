# 岗位培训卡（权衡）

## 学习目标
1. 理解岗位在流水线中的位置：最后一道防线，只有否决权没有创作权
2. 掌握外部调用协议：gate-check strict + 合规预检
3. 熟悉交接契约：H4 审核报告 + 退回机制

## 调用协议训练

| 场景 | 调用目标 | 调用方式 | 预期结果 |
|------|---------|---------|---------|
| AI 味硬判定（全队唯一判定源） | `gate-check.py` strict | `gate-check.py --strict <稿件路径>` | ≤5 放行 / 6-15 重写≥50% / >25 推倒 |
| 发布前合规风险自审 | `yuwen-publish-precheck` | skill 触发"审一下稿子" | 敏感词/违禁词定位 + 依据 + 替换稿 |
| 排版后图文 OCR 抽检 | `gate-H11-check.py` | `gate-H11-check.py <图路径>` | 首尾图及正文配图错字检测 |
| 图片水印合规检查 | `gate-H12-check.py` | `gate-H12-check.py <图路径>` | 违规水印检测结果 |
| 尾图合规验收 | `gate-H15-check.py` | `gate-H15-check.py <图路径>` | 无导流二维码/微信号/诱导词，高度≤800px |

**调用顺序**：事实核对 → 逻辑检查 → gate-check strict → 合规预检 → 生成审核报告。

## 交接演练

### 上游输入
- 模拟输入：成稿 + solo 分数 + 修改记录（来自 04）
- 必填字段检查：稿件是否有 5 个备选标题、正文是否≥200字、金句是否≥1

### 下游交接
- 交付物：审核报告 `YYYYMMDD_选题_审核报告.md` → 04 主笔（🔴/🟡 退回）或 06 排版（🟢 放行）
- 格式要求：每条 = 位置（节号或原文 10 字内）+ 问题描述 + 修改建议 + 依据
- 问题分级：🔴 致命 / 🟡 重要 / 🟢 建议
- 交接确认：下游回复"已收/逐条复核完毕"

### 异常处理
- **🔴 致命项 >0**：打回 04，写明"哪一条字段不达标"，不接受"改好了"三字
- **脚本判定与人工判断冲突**：以 gate-check strict 为准，人工只判脚本判不了的（事实准确性、观点一致性）
- **越界预警**：发现自己准备改句子 → 停手，只给意见不改稿

## 考核标准

- **岗位理解**：能否说明"只有否决权，没有创作权"的边界（0-10 分）
- **调用能力**：能否正确运行 gate-check strict + yuwen-publish-precheck（0-10 分）
- **交接能力**：审核报告是否逐条定位（有行号/原文引用）、分级是否准确（0-10 分）
