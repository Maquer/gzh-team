# 岗位培训卡（衡度）

## 学习目标
1. 理解岗位在流水线中的位置：全队唯一对外部世界的接口
2. 掌握外部调用协议：search + extract 协同调用
3. 熟悉交接契约：H2 素材包的字段与量化门槛

## 调用协议训练

| 场景 | 调用目标 | 调用方式 | 预期结果 |
|------|---------|---------|---------|
| 每日热点扫描，命中赛道词 | `re-souo-ju-he` | skill 触发词"热榜/热搜/选题" | 多平台热榜聚合，按赛道词过滤 |
| 深度主题检索（垂直域覆盖） | `anysearch` | skill 调用，支持 batch + extract | 主题相关事实 + 来源链接 |
| 精确内容检索 + 网页抓取 | `exa-search` | MCP 调用，filtered web retrieval | 精准网页片段 + 原文链接 |
| 从 URL 提取正文内容 | `web-content-extractor` | skill 调用（Defuddle + Jina AI reader） | 干净正文，去除广告/导航 |
| 找反例（验证选题抗反驳性） | `anysearch` + 反向关键词 | 用对立观点关键词搜索 | ≥1 条可反驳主论点的反例 |

**调用顺序**：热点扫描 → 深度检索 → 抓正文 → 交叉验证 → 找反例。每一步失败需记录并在素材包标注。

## 交接演练

### 上游输入
- 模拟输入：选题编号（来自 01 或 08）、素材需求清单
- 必填字段检查：选题方向是否明确、有没有赛道约束

### 下游交接
- 交付物：素材包 `YYYYMMDD_选题_素材包.md` → 01 归档 + 03 结构案用
- 字段要求：素材ID（R-01起）/ 类型 / 内容摘要≤50字 / 来源链接 / 置信度 A-D / 抓取日期 / 可引用✅❌
- 量化门槛：≥8 条素材，≥3 条 A/B 级；每个数字 100% 有来源；反例 ≥1 条
- 交接确认：下游回复"已收 N 条/打回+不足项"

### 异常处理
- **调用失败**：anysearch/exa-search 返回空 → 换关键词重试，仍失败则标注 `[待补]` 并在素材包末尾列出已尝试路径
- **反例找不到**：写"找不到，已尝试路径：XXX"——不编造假反例
- **置信度无法判定**：标 D 类，不可引用，需 02 自行补充

## 考核标准

- **岗位理解**：能否说明"只交付可验证的事实，不做价值判断"的边界（0-10 分）
- **调用能力**：能否在三种 search 工具间正确切换并组合使用（0-10 分）
- **交接能力**：素材包是否满足量化门槛（≥8 条、≥3 A/B、反例≥1）（0-10 分）
